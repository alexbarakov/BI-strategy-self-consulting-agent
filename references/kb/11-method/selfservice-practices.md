Каталог для развития BI-сообщества. По каждому пункту оценивается: **применимо? · ответственный драйвер · сроки**. Смысл упражнения — не внедрить всё, а осознанно отобрать 3–5 и назначить владельца; пункт без драйвера равен пункту «не применимо».

## Инструменты и практики (16)

| Практика | Что делает |
|---|---|
| **Intro** | связывает новых пользователей с нужными ресурсами интранета |
| **FAQ и база знаний** | ответы на частые вопросы, экономит время команды |
| **Support Options** | куда идти за поддержкой: peer-to-peer, уровни сервиса, workflow сервис-деска |
| **Notifications and announcements** | встречи юзер-групп, планы обучений, новые курсы, отчёты, релизы |
| **BI User Directory** | делает участников BI-проекта находимыми, облегчает обмен идеями и поиск помощи |
| **Governance Models in public** | публично объясняет, какая модель (centralized / delegated / self-managed) применяется к каким данным и контенту |
| **Data Platforms** | все настройки подключения: имя БД, таблицы, порты, требования к запросу доступа |
| **Certified Data** | публикация и маркировка доверенных данных, реестр сертифицированных источников |
| **Analytics Best Practices** | как выбрать тип графика, как делать actionable-дашборды, data storytelling |
| **Visual Style Guide** | шрифты, брендовые цвета, форматирование, шаблоны и визуальные каталоги |
| **Events & Education Calendar** | календарь BI-событий, продвигаемых «как рок-концерты» |
| **Learning Plans** | планы обучения под каждую роль |
| **Training Videos** | свой набор обучающих видео, в том числе по запросу пользователей |
| **User Group Recordings** | записи встреч внутренних юзер-групп с таймкодами |
| **Analytics Blog/Newsletter** | блог о достижениях и о том, как данные используются в компании |
| **Discussion Forums & Chat** | реалтайм-обмен |

## Типы событий (7)

Internal User Group (канал в интранете предпочтительнее группы на портале) · Internal Champions Group · Internal Admin Group · **Open 30 min events** («How We Do It», «Ask Us Anything», Lunch & Learn) · Deep Dive Seminar / Boot Camp · **Viz Games** (хакатон по визуализации с задачей, замером и победителями) · Analytics Day / внутренняя конференция.

## Типы поддержки (6)

User Support Process · **Champion Development** (поиск, обучение и развитие BI-чемпионов внутри бизнес-функций) · Certifications (помощь в получении сертификатов по ETL и BI) · **Skills Pyramid** (развитие навыков по матрице с продвижением по уровням) · Mentoring program · **Service like Tableau Doctor** (запись на hands-on сессию под конкретную задачу).

## Полевое подтверждение

Формат «BI-академия» — еженедельные открытые полуторачасовые консультации центра компетенций из 4 человек для команды из 30 аналитиков — по свидетельству участника курса заметно поднял качество UI/UX дашбордов, которые аналитики делают сами. См. [[participants-2026-benchmark]].
