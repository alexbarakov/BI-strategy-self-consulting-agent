The catalog for growing the BI community. Each entry is assessed on: **applicable? · the driver responsible · timing**. The point of the exercise is not to roll everything out but to deliberately pick three to five and name an owner; an entry with no driver is equivalent to an entry marked "not applicable".

## Tools and practices (16)

| Practice | What it does |
|---|---|
| **Intro** | connects new users to the intranet resources they need |
| **FAQ and knowledge base** | answers to frequent questions, saving the team's time |
| **Support options** | where to go for help: peer-to-peer, service levels, the service-desk workflow |
| **Notifications and announcements** | user group meetings, training plans, new courses, reports, releases |
| **BI user directory** | makes the BI project's participants findable, making it easier to trade ideas and find help |
| **Governance models in public** | publicly explains which model (centralized / delegated / self-managed) applies to which data and content |
| **Data platforms** | all connection settings: database name, tables, ports, requirements for requesting access |
| **Certified data** | publishing and marking trusted data, a registry of certified sources |
| **Analytics best practices** | how to choose a chart type, how to make dashboards actionable, data storytelling |
| **Visual style guide** | fonts, brand colours, formatting, templates and visual catalogs |
| **Events & education calendar** | a calendar of BI events promoted "like rock concerts" |
| **Learning plans** | learning plans for each role |
| **Training videos** | your own set of training videos, including ones made on user request |
| **User group recordings** | recordings of internal user group meetings, with timecodes |
| **Analytics blog / newsletter** | a blog about achievements and about how data is used across the company |
| **Discussion forums & chat** | real-time exchange |

## Event types (7)

Internal user group (an intranet channel is preferable to a portal group) · internal champions group · internal admin group · **open 30-minute events** ("How We Do It", "Ask Us Anything", lunch and learn) · deep dive seminar / boot camp · **viz games** (a visualization hackathon with a task, a measurement and winners) · analytics day / an internal conference.

## Support types (6)

The user support process · **champion development** (finding, training and growing BI champions inside the business functions) · certifications (helping people obtain ETL and BI certifications) · **a skills pyramid** (skill development against a matrix with progression through levels) · a mentoring programme · **a service in the mould of Tableau Doctor** (booking a hands-on session for a specific task).

## Field confirmation

The "BI academy" format - weekly open 90-minute consultations run by a four-person competence centre for a team of 30 analysts - noticeably raised the UI/UX quality of the dashboards the analysts build themselves, according to a course participant. See [[participants-2026-benchmark]].
