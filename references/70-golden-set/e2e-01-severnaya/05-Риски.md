# 05. Риски

| Риск | Вероятность / влияние | Фактор снижения | Владелец | Триггер |
|---|---|---|---|---|
| **Инженера не нанимают** — стратегия остаётся планом для подрядчика | высокая / критическое | гейт стратегии: без найма до марта S2–S4 переносятся и стратегия пересобирается, а не исполняется наполовину | спонсор | 1 марта позиция не закрыта |
| **Подрядчик — единая точка отказа** | средняя / высокое | реестр мастер-источников описывает объекты так, чтобы их мог поддержать не автор; передача знаний в договор | рук. ИТ | срок по заявке вырос вдвое либо ушёл ключевой человек подрядчика |
| **Миграция платформы съедает год** | высокая / высокое | миграция не начинается по объектам вне реестра; сначала описание, потом перенос | рук. ИТ | план миграции содержит объекты, которых нет в реестре |
| **Владелец домена не назначен** — S2 некому подтверждать | средняя / критическое для S2 | стрим останавливается явно, а не согласуется «по факту» | рук. BI | 1 апреля имени нет |
| **Governance объявлен без ресурса** | средняя / высокое | не заводим DG-функцию; правила живут внутри S1 и S5 как часть работы инженера и комплаенса | рук. BI | появляется регламент, у которого нет исполнителя |
| **Домен держится на одном человеке** | средняя / высокое | второй человек в контуре продаж со второго года; запись передачи знаний с первого дня | рук. ИТ | единственный носитель знания уходит в отпуск и работа встаёт |
| **Смена приоритета после ноября** | средняя / высокое | список заморозки опубликован заранее; сокращение исполняется по нему, а не переговорами | спонсор | бюджет урезан либо сменился спонсор |
| **Self-service открыт до разделения ПДн** | низкая / критическое | S5 объявлен блокирующим для S3 в [[02-Стримы]] | комплаенс | появилась заявка на доступ категории до завершения S5 |

## <a id="freeze"></a>Список заморозки

Публикуется заранее. При потере трети ресурса замораживается сверху вниз:

1. **S3 · Управляемый self-service** — первым. Даёт эффект только после S1, а без ресурса S1 не завершится. Замораживается целиком, а не «пилотом на одной категории».
2. **S4 · Платформенный переход** — в части сроков, не отменяется: миграция внешняя. Замораживается наша приёмка сверх минимума.
3. **S2 · Слой метрик** — сокращается до трёх согласованных определений без вынесения в код.

**Не замораживаются ни при каком сокращении:** S1 в части реестра и дата-контрактов и S5 целиком. Первое — потому что без него сокращение обнуляет всё остальное; второе — потому что это регуляторное требование, а не улучшение.

> **Проверка честности списка.** Если сокращение бюджета наступит, а список окажется неудобным — значит, он составлен правильно. Список, с которым все согласны заранее, обычно не резал ничего.
