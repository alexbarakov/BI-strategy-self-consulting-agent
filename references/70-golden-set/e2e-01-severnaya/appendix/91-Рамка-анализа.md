# 91. Рабочая рамка анализа

Семь блоков рамки — инструмент проработки. В документ вынесен результат; здесь фиксируется, что выяснили по каждому блоку и куда это ушло.

| Блок | Что выяснили | Куда ушло |
|---|---|---|
| **1. Бизнес-основа** | Домены не выделены, владельцев нет. Ключевые сущности — продажи, остатки, лояльность. Потребители: коммерция, категории, логистика, финансы | Проблемы P1, P3 → S1, S2 |
| **2. Оценка ландшафта** | Средний уровень 1,5; AI-readiness ноль по трём измерениям из пяти; adoption не измеряется | [[90-Диагностика]], проблема P4 |
| **3. Целевая операционная модель** | Сейчас чистый centralized с элементами стихийного self-service. Целевая — guided для руководителей, управляемый self-service для категорий | S3, границы в [[../02-Стримы]] |
| **4.1 Управление данными** | Процессов нет ни в одной из шести областей; ближе всего к существующему — мониторинг обновлений | S1: реестр и дата-контракты |
| **4.2 Управление контентом** | Валидация и релиз есть неформально; сертификации, архивации и замера использования нет | Частично S3; архивация отложена до замера adoption |
| **4.3 Управление инсайтами** | Не существует. Запрос коммерческого директора на ассистента — попытка перепрыгнуть сюда сразу | Гейт открытия ассистента в [[../04-Цели]] |
| **5. Технологическая основа** | DWH есть, слоя метрик нет, каталога нет. Миграция BI идёт вне контроля BI-команды | S1, S2, S4 |
| **6. Операционная основа** | Регулярных встреч по governance нет, матрицы прав нет, стандартов нет. Компетенции аналитиков не описаны | S5 в части прав; остальное отложено осознанно |
| **7. Управление изменениями** | Бюджет не выделен, решение в ноябре — это и есть главная развилка стратегии | [[../index]] запрос к спонсору, [[../05-Риски]] |

## Блоки, не попавшие ни в один стрим

- **Управление инсайтами (4.3)** — сознательное решение: инсайты недостижимы до закрытия первого звена цепочки. Записано в «чего мы не делаем».
- **Часть операционной основы (6)** — стандарты, компетенции, регулярный менеджмент. Отложены не по важности, а по ресурсу: команда из трёх человек не потянет их параллельно с S1. Возвращаемся на пересборке через полгода.
