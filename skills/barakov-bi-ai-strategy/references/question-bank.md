# Банк вопросов диагностики

Реальные формулировки из **BI Project Health Check** (72 фактора, 9 категорий) + **AI-readiness оверлей** курса + ссылки на questionnaire-листы D&A Planner. Использовать как источник вопросов интервью — не выдумывать свои.

Каждый фактор оценивается по шкале **0–4**: 0 No · 1 Planned · 2 In Progress/Partially · 3 Completed (need improvement) · 4 Fully Completed & Optimized. Участник ставит **текущую оценку и 1Y-таргет**.

Как использовать по режимам:
- **Лайт:** после 8 контекст-вопросов задай **само-оценку по 9 категориям** (одна оценка 0–4 на категорию, опираясь на «якорный» вопрос ниже) + **5 оценок AI-readiness**. Этого достаточно для честного скоркарда.
- **Полный:** прогони факторы по-штучно (грид), считай средние по категориям и по 7 solution-категориям.

## 1. Connection with business (Business Alignment / Data Culture)
- 1.1 Реестр аналитических кейсов, ранжированный по ценности для бизнеса?
- 1.2 Отчёты встроены в регулярные бизнес-процессы и cadence принятия решений?
- 1.3 Инициативы BI согласованы со стратегическими и операционными целями бизнеса?
- 1.4 Бизнес-лидеры вовлечены в BI и продвигают культуру данных?
- 1.5 Персоны целевой аудитории BI чётко определены и классифицированы?
- 1.6 Дерево бизнес-метрик определено и стандартизировано?

## 2. Adoption and Satisfaction (User Engagement)
- 2.1 Есть инструменты мониторинга использования отчётов (BI-for-BI)?
- 2.2 Регулярно оцениваете adoption BI-инструментов?
- 2.3 Доля активных пользователей в месяц > 50% для ключевых ролей?
- 2.4 Adoption входит в цели BI-команды?
- 2.5 Регулярные опросы удовлетворённости пользователей?
- 2.6 Есть фреймворк сбора фидбека от конечных пользователей?
- 2.7 Есть процесс онбординга новых пользователей с рекомендациями?

## 3. BI Content management (Processes & Standards)
- 3.1 Определены критерии приёмки задач, согласованные с бизнесом?
- 3.2 Документированный фреймворк сбора требований?
- 3.3 Каждый релиз/апдейт отчёта проходит чек-лист качества?
- 3.4 Есть процесс документирования отчётов (источники, мета, логика)?
- 3.5 Есть маркировка/сертификация рекомендованных отчётов бизнес-владельцами?
- 3.6 Регулярные ревью отчётов с владельцами данных?
- 3.7 Отчёты интегрированы с корпоративным глоссарием?
- 3.8 Есть процедура архивации устаревших/неиспользуемых отчётов?
- 3.9 Отслеживается время загрузки отчётов против нормы?
- 3.10 Есть workflow улучшения производительности + SLA здоровья контента?
- 3.11 Есть визуальный стайл-гайд для дашбордов?

## 4. Self-Service BI Delivery (баланс моделей, community)
- 4.1 Гармонизированы централизованная и self-service модели?
- 4.2 Механизм консистентности методологий и инструментов между SSBI-авторами?
- 4.3 Есть портал/канал коммуникации для SSBI?
- 4.4 Процесс передачи и ревью контента между авторами?

- 4.6 Структурированные learning paths?
- 4.7 Community-активности: митапы, demo days, обмен знаниями?
- 4.8 Регулярные тренинги и менторство для SSBI-пользователей?

## 5. Guided BI Service Delivery (support, UX)

- 5.5 Пользователи имеют доступ к данным и могут работать самостоятельно?
- 5.6 Отчёты оптимизированы под мобильные/планшеты?

## 7. Data Quality management (Processes & Standards)
- 7.1 Отчёты обновляются автоматически по расписанию?

- 7.3 **Слой сертифицированных источников** для доменов/метрик?

- 7.6 Прозрачность свежести данных (время выгрузки, задержки) в отчётах?

## 8. BI security and compliance (Processes & Standards)
- 8.1 Ролевой доступ (RBAC)?
- 8.2 Авто-назначение ролей по правилам?
- 8.3 Workflow запроса доступа с авто-аппрувом?
- 8.4 Интеграция с Active Directory (или аналог)?
- 8.5 Регулярные аудиты безопасности доступов?
- 8.6 Комплаянс (GDPR/HIPAA/152-ФЗ)?

## 9. Project Management (Processes & Standards / Skills)
- 9.1 Система приоритизации BI-проектов?
- 9.2 Ведение задач в трекере (Jira)?
- 9.3 Agile (Kanban/Scrum со спринтами и ретро)?
- 9.4 Матрица компетенций BI-команды?

- 9.6 Годовые цели команды согласованы со стратегией D&A?
- 9.7 Долгосрочный стратегический план развития BI?
- 9.8 Стандартизированный найм и онбординг BI-специалистов?

## AI-readiness оверлей (10-я условная категория, слой курса)

Оценивай так же 0–4:
- **AI-1 Семантическое покрытие** — доля ключевых метрик с однозначным определением в semantic layer / metric store.
- **AI-2 Trusted core** — доля запросов/отчётов на certified core-слое; ownership/SLA/DQ на витринах.
- **AI-3 Доменный контекст (ДБЗ)** — полнота доменной базы знаний: объекты, глоссарий, FAQ, примеры «вопрос→SQL», eval-кейсы.
- **AI-4 Готовность процессов** к «AI генерирует — человек проверяет» — verify-gate (BI Partner), kill-gates, eval-инфраструктура.
- **AI-5 Агентная инфраструктура** — MCP к сервисам, реестр скиллов, judge-gate/guardrails, наблюдаемость (трейсинг).

Плюс два поведенческих вопроса курса (не по 0–4, а фактом):
- Что пробовали с AI/LLM в аналитике и **что дожило до прода**?
- Какой **% ad-hoc** можно, по ощущению, закрыть AI без аналитика? (ориентир: SQL+доки ≈ 61%).

## Дополнительные questionnaire-листы Planner (для Полного режима)

Для более глубокого AS-IS по процессам — практики из D&A Planner (лист → что спрашивает):
- `2.1 Data Mgmt questionnaire` — процессы Data Source Mgmt, DQ, обогащение, безопасность (Centralized vs Self-Governing).
- `2.2 Content Mgmt questionnaire` — жизненный цикл контента, авторизация, валидация, промоушн.
- `2.3 SelfServ D&A Practices`, `2.4 Centralized D&A Practices` — чек-листы практик (Применимо? / Ответственный / Сроки).
- `2.5 BI & Around BI Tools` — инвентаризация стека, включая GPT-based BI UX и insight-generation.
