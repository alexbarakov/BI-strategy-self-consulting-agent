Канонический спайн метода. Гайд — рабочая тетрадь из 22 листов в 5 разделах. **Порядок листов и есть порядок работы**: заполнять слева направо, каждый следующий опирается на предыдущий.

Автор определяет BI-стратегию как **повторяемое упражнение из четырёх видов деятельности**: глубокий анализ потребностей и ландшафта D&A → пересборка высокоуровневого видения и целей → выработка конкретных решений и практик → планирование работы команды на полгода.

## Разделы и листы

| # | Раздел | Листы |
|---|---|---|
| **1** | **AS-IS Analysis** — потребности, ландшафт, ограничения | 1.1 D&A PainPoints · 1.2 Data Domains Classification · 1.3 User Classification and BI Models · 1.4 Info supply-demand matrix · 1.5 Outside BI · 1.5 Inside BI |
| **2** | **TO BE Design** — целевые роли, процессы, инструменты | 2.1 Data Mgmt processes + questionnaire + Critical data · 2.2 Content Mgmt Processes + questionnaire · 2.3 SelfServ D&A Practices · 2.4 Centralized D&A Practices + Analytical Workplaces · 2.5 BI & Around BI Tools |
| **3** | **Operational model and efficiency** | 3.1 Access Matrix · Regular Meetings · Rules and Standards · 3.2 Newcomer onboarding plan · 3.3 BI Project Metrics |
| **4** | **Transformation Plan** | 4. Action plan |
| **5** | **New D&A Vision** | 5. BI Vision |

## Как это ложится на 7 блоков скилла

Гайд — источник, `strategy-template.md` — выход.

- раздел 1 → блоки 1–2 (AS-IS)
- раздел 2 → блоки 3, 4.1, 4.2, 4.3, 5 (TO-BE)
- раздел 3 → блок 6 (операционная основа)
- разделы 4–5 → блок 7 (трансформация) и Vision

## Правило применения

Каждый лист — **упражнение с примерами заполнения**, а не теория. В артефакте участника должна остаться заполненная таблица, а не пересказ рамки. Если лист не заполняется, потому что данных нет, — это находка для блока 2, а не повод пропустить лист.
