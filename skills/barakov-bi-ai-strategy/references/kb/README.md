- **Курс «BI+AI стратегия 26»** — девять занятий, PDF-версии как читались участникам

## Соглашения по frontmatter

```yaml
id:          # kebab-case, совпадает с именем файла
title:       # заголовок
type:        # method | pattern | evidence | case | benchmark | catalog | metric
source:      # первоисточник
confidence:  # проверяемо | мерил продавец | нет данных | оценка автора | смешанная
origin:      # опционально: пометка для кейсов из практики с обезличенными числами
blocks:      # к каким блокам стратегии относится (1, 2, 3, 4.1, 4.2, 4.3, 5, 6, 7)
```

## Правила использования агентом

1. **Точка входа — `kb-graph.yaml`**: по номеру блока стратегии находишь список релевантных атомов.
2. **Цитируй атом, а не пересказывай KB целиком** — файлы нарезаны по одной теме именно для точечного цитирования.
3. **Переноси метку `confidence` вместе с цифрой.** Цифра с пометкой «мерил продавец» не превращается в факт при переносе в артефакт.
4. **Атомы с полем `origin` — разобранные кейсы из практики с обезличенными числовыми порогами.** Переносится конструкция и принцип; пороги ставятся от своего бейзлайна, а не копируются. Формулировки вида «примерно втрое», «около двух третей» — намеренные: важен порядок эффекта, а не чужая цифра.
5. **KB — источник, а не шаблон вывода.** Артефакт собирается по `strategy-template.md`, KB его заземляет.
